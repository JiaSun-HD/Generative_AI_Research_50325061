# Generative AI Research Project

This repository contains data, literature, reports, and scripts for our Generative AI research project.

## Folder Structure

- **Figures/** - Charts, diagrams, and schedules
- **Literature/** - Reference papers and reading materials
- **Reports/** - Research papers and project proposals
- **SurveyData/** - Survey datasets and python scripts
- **Transcripts/** - Interview transcripts

## File Naming Rules

To keep things organized for everyone, please follow these rules when adding files:

- Use underscores (`_`) instead of spaces.
- Include dates in `YYYYMMDD` format where appropriate.
- Use clear and descriptive names (avoid names like `final_final.docx`).

## Collaboration

- Pull the latest changes before starting your work.
- Keep your commit messages clear and descriptive (e.g., `Add interview transcript P4`).
- Avoid committing local system files like `.DS_Store`.
