# Generative AI Research Project (SID: 50325061)

## Project Overview
This repository contains the research data, analysis scripts, documents, and literature reviews for our study on "Using Generative AI Tools - Boon or Bane."

## Directory Structure
- `Data/`: Contains quantitative survey data, CSV, and Excel analysis files.
- `Scripts/`: Contains Python scripts and automation code.
- `Docs/`: Contains qualitative analysis reports, interview transcripts, and draft papers.
- `Literature/`: Contains journal articles, books, and reference materials.

## Collaboration Guidelines
1. **Branching Strategy**: Always create a new feature branch (e.g., `dev-feature-analysis`) for your updates. Do not push directly to `main`.
2. **Pull Requests**: Submit a Pull Request (PR) after committing your changes, and request a code review before merging.
3. **Commit Messages**: Write clear, descriptive commit messages describing what was added or modified.
